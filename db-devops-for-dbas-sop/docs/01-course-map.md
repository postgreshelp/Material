# DBA Automation Course Map

## Track 1 - Fundamentals

1. Terraform terminology and workflow
2. Ansible terminology and workflow
3. Liquibase terminology and workflow
4. Jenkins terminology and workflow

## Track 2 - DBA Operations

1. Infrastructure incidents
2. PostgreSQL operational incidents
3. Schema deployment incidents
4. CI/CD incidents

## Track 3 - End-to-End Production Workflow

```text
Requirement
 -> Git
 -> Terraform
 -> AWS PostgreSQL
 -> Ansible
 -> Liquibase
 -> Jenkins
 -> Verification
```

## Teaching rule

For every command, answer four questions:

1. What does it do?
2. What object does it change?
3. Who owns that object?
4. What production incident would make a DBA use it?
