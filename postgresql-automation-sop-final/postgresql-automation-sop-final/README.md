# PostgreSQL Automation Project

## Files

1.  `01-theory.md` --- isolated theory for Git, Terraform, Ansible,
    Liquibase and Jenkins.
2.  `02-architecture.md` --- conceptual, infrastructure, automation and
    end-to-end Mermaid diagrams.
3.  `03-step-by-step-implementation.md` --- progressive implementation
    from Git and Terraform through Ansible, Liquibase and Jenkins.

## Recommended teaching order

``` text
01 Theory
   ↓
02 Architecture
   ↓
03 Implementation
```

The implementation intentionally follows one continuous PayLite project
rather than unrelated tool demonstrations.
